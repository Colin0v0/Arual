**中文**

- **调整** 设备、应用和设置行改为轻量局部悬停，不再绘制整行灰框。
- **调整** 设置页改为中性分段控件和统一分组布局。
- **新增** 同时列出多副已连接耳机，并在不切换系统输出的情况下控制降噪。
- **新增** 合并发布分支后自动构建、校验和发布更新资产。
- **修复** 部分构建环境下应用资源包路径错误导致启动崩溃。
- **修复** SHA-256 校验文件包含构建机路径的问题。

**English**

- **Changed** Device, app, and Settings rows to lightweight local hover feedback without full-row gray backgrounds.
- **Changed** Settings to neutral segmented controls with consistent grouping and alignment.
- **Added** Multiple connected headphones with noise control that does not switch the system output.
- **Added** Automatic build, verification, and asset publishing after a release branch is merged.
- **Fixed** Startup crashes caused by an invalid resource bundle path in some build environments.
- **Fixed** SHA-256 files containing paths from the build machine.
