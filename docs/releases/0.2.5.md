**中文**

- **新增** 统一的耳机能力模型，电量形状、噪声档位和支持状态按真实型号显示。

**English**

- **Added** A unified headphone capability model so battery shapes, noise levels, and support status match the real model.
- **Added** Controls for Sony MDR V2, Bose QuietComfort series, and Sennheiser ACCENTUM Wireless.
- **Added** Apple headphone modes based on the capabilities actually exposed by macOS.
- **Fixed** Stale Bose state after mode readbacks, identity confirmation, and connection failures.
- **Fixed** Available controls being hidden on AirPods Max and other over-ear headphones when wear state is unknown.
