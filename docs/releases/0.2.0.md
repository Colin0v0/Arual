**中文**

- **新增** 应用级多设备路由，每个应用可选择当前输出组中的一台、多台或全部设备。
- **新增** “全部输出”自动包含后来加入的设备，自定义路由按应用身份保存并恢复。
- **新增** 系统音频原生授权流程，拒绝授权时显示 Aural 权限说明框。
- **修复** Chrome 输出元数据为空时阻止应用音频捕获。
- **修复** 音频格式变化或设备重连后应用音量、电平和路由持续等待。

**English**

- **Added** Per-app multi-device routing so each app can target one, several, or every output in the current group.
- **Added** All Outputs automatically includes devices added later, while custom routes persist by app identity.
- **Added** A native system-audio permission flow with an Aural explanation dialog after denial.
- **Fixed** Empty Chrome output metadata blocking app audio capture.
- **Fixed** App volume, meters, and routing waiting indefinitely after format changes or device reconnects.
