**中文**

- **新增** 每个正在播放的 App 独立音效窗口；原来的音量、静音和输出路由保持不变。
- **新增** 十段推子、小幅频响预览和六个内置预设；拖动时声音即时跟随，松手后保存。
- **新增** 保存当前配置、重命名和删除自定义预设，以及用于快速听前后差别的「对比原声」。
- **改进** 曲线、频段标签与推子统一对齐，窗口更紧凑；预设操作集中在顶部工具栏。
- **新增** 设置页「启用应用音效」总开关；关闭后立即恢复原声并保留各 App 的配置。

**English**

- **Added** A dedicated effects window for each playing app; volume, mute, and output routing stay unchanged.
- **Added** Ten faders, a compact response preview, and six built-in presets; changes are heard while dragging and saved on release.
- **Added** Save as Preset, rename and delete for selected custom presets, and Compare Original for a quick listen before and after.
- **Improved** Aligned response grid, frequency labels, and faders in a tighter window; preset actions now live in the top toolbar.
- **Added** A global Enable App Effects switch in Settings that turns effects off immediately while remembering each app’s settings.
