**中文**

- **修复** 系统音频授权回调过早释放导致应用崩溃。
- **修复** 首次启动没有真正触发 macOS 系统音频授权框。
- **修复** 权限被拒绝后进入不可用界面，现在可直接打开系统设置或退出。
- **修复** 运行期间权限失效后没有停止应用音频处理。
- **修复** 应用音量、电平和路由在 Chrome 元数据或音频格式变化后停止工作。
- **修复** 使用独立版本资产重新打包，不覆盖 0.2.0 的安装包和校验文件。

**English**

- **Fixed** A crash caused by releasing the system-audio permission callback too early.
- **Fixed** First launch not triggering the actual macOS system-audio prompt.
- **Fixed** Entering an unusable interface after denial; users can now open System Settings or quit.
- **Fixed** App audio processing not stopping when permission was revoked at runtime.
- **Fixed** App volume, meters, and routing stopping after Chrome metadata or audio format changes.
- **Fixed** Repackaged with independent versioned assets instead of overwriting 0.2.0 packages and checksums.
