**中文**

- **新增** 左耳、右耳和充电盒的独立电量显示。
- **调整** Apple 耳机仅在双耳均确认佩戴时显示降噪、通透和自适应控制。
- **修复** 部分工具链构建后无法从正确资源包启动的问题。
- **修复** 资源诊断可能误用构建目录资源包的问题。
- **修复** 重新打包 0.1.13 和 0.1.14，旧安装包需要手动覆盖。

**English**

- **Added** Separate battery readings for the left earbud, right earbud, and charging case.
- **Changed** Apple headphone noise, transparency, and adaptive controls to appear only when both ears are confirmed worn.
- **Fixed** App startup failing to load resources from the correct bundle with some toolchains.
- **Fixed** Resource diagnostics potentially using a bundle from the build directory.
- **Fixed** Repackaged 0.1.13 and 0.1.14; earlier installations require a manual replacement.
